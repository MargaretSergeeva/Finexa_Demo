Finexa · Data Pipeline Architecture

AI-Augmented Feedback Intelligence · Payments Domain

End-to-End Flow

1 · Ingest
CRM
Salesforce / HubSpot notes
Support
Zendesk / Intercom tickets
Interviews
Call notes, research
Other
NPS, surveys, Slack
→ Written to raw_feedback
↓
2 · De-identify
Google Cloud DLP
PII removal / masking
→
Clean text stored back on raw_feedback.raw_text
↓
3 · Structure (LLM Agent 1)
LLM Structuring Agent
Extracts summary, pain points, root cause, theme, severity, segment…
→
Writes to processed_insights
+ generates embedding (VECTOR)
↓
4 · Match (Vector + LLM)
Vector Search
Find similar opportunities in insight_repository using embedding
LLM Re-ranker
Reads candidates + insight → decides match confidence + reason
→ Results written to candidate_shortlist (score, rank, llm_match_reason)
↓
5 · Human Gate 1 — Confirm Insight & Opportunity
Human decides
Accept & attach
Link to existing opportunity
Create new
New opportunity is born
Reject
Archive the insight
Writes to gate_decisions · updates processed_insights · creates/updates insight_repository
↓
6 · Score (Deterministic)
Scoring Engine
Uses scoring_weights + strategic_priorities
→
priority_score + priority_explanation
Status moves to logged then prioritized
Re-scoring can happen anytime (new insights, weight changes) without changing status.
↓
7 · Human Gate 2 — Approve for Engineering
Human reviews score explanation
Approves opportunity → sets approved_for_drafting = true
Logged in gate_decisions
↓
8 · Draft Jira Ticket (LLM Agent 2)
Engineering Draft Agent
Creates problem statement, user story, acceptance criteria, complexity estimate
→ Writes to jira_tickets (status = draft)
↓
9 · Human Gate 3 — Review Draft + Complexity
Engineer / PM reviews draft
Edits if needed, sets complexity, confirms → status becomes confirmed_draft
↓
10 · Sprint Selection & Push to Jira
Team selects
From approved drafts → status = selected
Wrapper pushes
Creates real Jira issue → status = sent
↓
11 · Jira Sync & Regression Detection
Jira Sync Job
Polls / webhook → updates current_jira_status + jira_status_log
Regression logic: If Jira = Done and new similar insights keep arriving → set regression_flag = true and surface the opportunity again.
When Jira Done + no new insights → opportunity status = resolved
Agent 1 · Structuring
  • • Turns raw text → structured insight
  • • Generates embedding
  • • Suggests theme & severity
Agent 2 · Matching
  • • Vector search candidates
  • • LLM decides match + reason
  • • Writes shortlist
Agent 3 · Drafting
  • • Creates Jira-ready ticket
  • • Suggests complexity
  • • Human reviews before push
